# Month and year report charts

- Revision: 1; status: approved.
- Goal: replace the crowded month/year pie with the compact weekly chart's visual language. Month uses Monday–Sunday buckets clipped to the selected month; year uses one bar per month. Bars represent filtered time, not projects.
- Existing calendar navigation, period and project filters, editing, deletion, time and revenue totals remain available in production. The existing month/year grouped summary limitation is unchanged and is not represented by the demo.
- Browser mockup approximates the iPhone interface; data, filtering and navigation are illustrative. Switch Monat/Jahr and light/dark to compare; empty state is available via review controls. Labels and sample totals are not date-calculated. No real data, backend or persistence.
