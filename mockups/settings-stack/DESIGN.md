# Settings stack mockup

- Revision: 5
- Status: Approved by user for implementation, revision 5.
- Goal: Settings opens as an app-wide sheet, with nested destinations pushed within it and no Done control; dismiss using the sheet gesture or backdrop. The back button from first-level destinations is icon-only.
- Debug uses a consistent grouped canvas and white section surfaces instead of a white outer area around a gray list.
- Scope: Today → Settings → Debug → Local Logs, back navigation, and simulated toggles. Other routes are placeholders.
- Logout and database reset are intentionally inert; existing behavior is not proposed for removal.
- Browser approximation only; native sheet behavior, navigation, colors, and content need production confirmation.
